# Чек-лист

Небольшой список дел, который не требует аккаунта.

- фильтрует все, активные и выполненные задачи;
- хранит срок с датой и временем;
- планирует одноразовое напоминание через WorkManager;
- отменяет напоминание после выполнения или удаления;
- на Android 13+ спрашивает разрешение только при включении напоминания.

## Стек и устройство

Kotlin, Compose/Material 3, Room/KSP, WorkManager, ViewModel + StateFlow. Room и планировщик находятся в `Data.kt`, уведомление — в `ReminderWorker.kt`, экраны — в `MainActivity.kt`.

## Запуск

`./gradlew test assembleDebug` (JDK 17, Android SDK 37).

## Известные ограничения

WorkManager гарантирует выполнение работы, но не доставку уведомления в точную минуту: энергосбережение устройства может дать небольшую задержку. Повторяющихся напоминаний нет.
